# 電腦看不到 iPhone 的照片？照這張圖檢查

從「iPhone 還沒插上電腦」到「看得到 `Apple iPhone / Internal Storage / 202408__` 這些資料夾」，
中間會卡住的地方就這幾個。照著檢查一遍通常就會通。

> 💡 **先用 Windows 檔案總管檢查，不要用這個工具。**
> 如果檔案總管都看不到，這個工具一定也看不到 —— 它們走的是同一條路。
> 先確認檔案總管看得到，再回來用這個工具。

## 每一步的細節

### 1. 電腦是 Windows 10 或 11？

按 **Win + R**，輸入 `winver` 再按 Enter，就會顯示版本。

Windows 7／8 沒辦法用，這是硬性限制（程式用的圖形介面框架已經不支援那些版本）。

### 2. 「本機」裡看得到「Apple iPhone」嗎？

打開檔案總管（**Win + E**），左邊點「本機」。應該會在 C 槽、D 槽那些磁碟機**旁邊**
看到一個叫「Apple iPhone」的東西。

**看不到的話，最常見的原因是 USB 線。** 很多線只能充電、不能傳資料，
外觀完全看不出來。手邊有別條線就換一條試試，優先用 iPhone 原廠附的那條。

其他依序試：

- **換一個 USB 孔** —— 插桌機後方主機板上的孔，避開延長座、USB hub、螢幕上的孔
- **手機和電腦都重新開機** —— 聽起來敷衍，但 MTP 連線卡住時真的有效
- **安裝「Apple 裝置」** —— 到 Microsoft Store 搜尋「Apple 裝置」（Apple Devices）安裝。
  Windows 10/11 大多不用裝就能認到 iPhone，但少數電腦需要

### 3. 手機解鎖了嗎？

**螢幕鎖著的時候，電腦讀不到 iPhone 裡的東西。** 而且 iPhone 過一陣子會自動鎖回去，
所以備份過程中最好讓螢幕保持亮著（設定 → 螢幕顯示與亮度 → 自動鎖定 → 永不）。

### 4. 「信任這部電腦」

第一次把 iPhone 接上某台電腦時，手機會跳出這個詢問。**要點「信任」，然後輸入手機密碼。**

不小心按到「不信任」的話，把 USB 拔掉重插，通常會再問一次。

如果重插好幾次都不再問了，在手機上：
**設定 → 一般 → 移轉或重置 iPhone → 重置 → 重置位置與隱私權**，
之後重新插上就會再問一次。

### 5. ⏳ 按了「信任」之後，還要再等 1～2 分鐘

**這是最多人誤會的一步。**

點了「信任」之後，`Internal Storage` 裡面**還是空的**，要再過一到兩分鐘
（照片多的話更久）才會出現資料夾。這段期間手機正在整理要給電腦看的清單。

**這時候用檔案總管進去看也是空的 —— 這是正常現象，不是程式壞了。**

等一下之後，在這個工具裡按**「重新整理裝置」**，或在檔案總管按 **F5**。

### 6. 還是空的 → 先改成「自動」

如果等很久都還是空的，把手機設定改一下比較容易讀到：

**設定 → App → 照片 → 傳送到 Mac 或 PC → 選「自動」**

<img src="img/iPhone_app_setting.jpg" width="320" alt="iPhone 的照片設定畫面">

**改完一定要把 USB 線拔掉重插**，不然設定不會生效。

> ⚠ **注意這個取捨**：「自動」比較容易讀到，但備份**影片**時手機要即時轉檔，
> 複製速度常常會掉到 0 位元組、卡住好幾分鐘。
>
> 所以建議的順序是：
> 1. 先用「自動」讓電腦讀得到資料夾，確認整條路是通的
> 2. 之後要備份影片時，再改回**「保留原始檔」**並重新插拔 USB
>
> 詳見 [README 的「複製速度變成 0 位元組」](../README.md#複製速度變成-0-位元組)。

## 都試過了還是不行 → 產生診斷報告

程式的工具列上有一顆**「產生診斷報告」**按鈕。按下去會在**桌面**產生一個
`iPhoneBackpacker-診斷報告-日期時間.txt`，把那個檔案傳給開發者就好。

> 💡 如果是「某個資料夾的檔案數看起來不對」，**先在左邊點選那個資料夾再按**，
> 報告會多做一段針對它的逐項檢查。

報告裡有什麼：

- 你的 Windows 版本、程式版本
- 「本機」底下每個項目，以及程式為什麼判定它是不是 iPhone
- 照片資料夾的完整清單
- 你選取的那個資料夾裡實際有什麼
- 程式最近的執行紀錄

**裡面只有裝置與資料夾的名稱，不包含你的照片。**

然後到 [GitHub Issues](https://github.com/3chdog/iPhone-Backpacker/issues)
開一個問題，附上那個 .txt，並說明你卡在上面流程圖的哪一步。
